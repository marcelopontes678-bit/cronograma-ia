# Triagem de currículos com IA

Cadastre as vagas, envie os currículos (PDF, DOCX, TXT) e receba o ranking de
cada função com um resumo dos melhores candidatos. A IA faz a primeira leitura;
a decisão é sempre de uma pessoa.

O acesso é protegido por senha. Abra pelo endereço direto do Space
(`https://<usuario>-<space>.hf.space`): o navegador não mostra a janela de
senha dentro da página do Hugging Face.

Código-fonte e documentação: pasta `triagem-curriculos/` do repositório
`cronograma-ia`.
