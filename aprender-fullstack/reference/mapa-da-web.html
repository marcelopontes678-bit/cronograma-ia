A viagem de um clique

  1. Você digita um endereço ou clica num botão (o navegador é o cliente).
  2. O DNS troca o nome do site pelo IP do servidor.
  3. O navegador envia uma requisição HTTP.
  4. O servidor executa o backend e, se precisar, consulta o banco.
  5. A resposta volta (página ou dados) e o navegador monta a tela.

Onde ver isso acontecendo

F12 → aba Network → F5. Cada linha é uma requisição. O filtro Fetch/XHR mostra só os pedidos de dados. Status 200 significa "deu certo".

Onde entra a IA

  • Dentro do app: a IA é mais um servidor. O código faz uma requisição (fetch) para a API e recebe uma resposta.
  • Para programar: o assistente escreve código em qualquer camada. Você decide a camada e revisa o resultado.
  • Quando quebra: primeiro descubra a camada (a aba Network ajuda), depois corrija.
